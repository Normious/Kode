# Operations: Kode

## Run locally

```bash
npm install
npm run migrate
npm run seed
npm start            # PORT 4009, health at /health
node scripts/test-local.js   # 19 checks
```

## Run in Docker (verified)

```bash
docker compose up --build -d
docker exec kode node src/seed.js   # one-time (fresh volume)
node scripts/test-local.js          # 19/19 against the container
```

`.dockerignore` excludes `node_modules`: **never ship host binaries into the
Linux image** (Windows-built `better-sqlite3` crashes with `invalid ELF
header`). Compose maps `4009:4009`, sets `NODE_ENV=production` +
`DATABASE_PATH=/app/data/kode.db`, persists `kode_data` volume. PM2
alternative: `ecosystem.config.js`.

## Troubleshooting

| Symptom | Cause → Fix |
| :--- | :--- |
| `invalid ELF header` in container | host `node_modules` copied in → ensure `.dockerignore`, rebuild |
| Port 4009 busy | stale `node src/server.js` → kill it before `compose up` |
| 401 on every call | wrong/missing `X-API-Key` → `seed` first, check header |
| 422 on scan | no detectable QR → check image, try larger/higher-contrast |
| Empty history/stats | fresh volume → expected; seed + generate first |
| Dev boot hang (Windows) | `pino-pretty` transport → run `NODE_ENV=production` (fallback exists) |

## Performance (spec §12)

Generate PNG-400 ≈ 5–15 ms · SVG ≈ 3–8 ms · batch-50 ≈ 300–600 ms ·
scan 800² ≈ 30–80 ms. PNG ≈ 2.5 KB @400 px. Optimizations: Sharp raw buffers
(no temp files), multi-pass scan, SVG for vector use.
