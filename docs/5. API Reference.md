# API Reference: Kode

Base `http://localhost:4009`. All `/qr/*` require `X-API-Key`. Key under test:
`dobadoba-qr-key-2026`.

## Generate

`POST /qr/generate`: `{data*, format(png|svg|datauri|json), size 100–2000,
margin 0–10, error_correction L|M|Q|H, foreground, background, content_type,
metadata}`. PNG/SVG return binary (+ `X-QR-*` headers); `datauri`/`json`
return JSON.

```bash
# PNG
curl -X POST localhost:4009/qr/generate -H "X-API-Key: KEY" \
  -H 'Content-Type: application/json' \
  -d '{"data":"https://dobadoba.com/pay/TXN-12345","size":400}' \
  --output pay.png
# SVG / DataURI
curl -X POST localhost:4009/qr/generate -H "X-API-Key: KEY" \
  -H 'Content-Type: application/json' \
  -d '{"data":"https://shop-a.com/products/42","format":"svg","size":300}' --output p.svg
curl -X POST localhost:4009/qr/generate -H "X-API-Key: KEY" \
  -H 'Content-Type: application/json' -d '{"data":"Hello!","format":"datauri"}'
```

## Presets

`POST /qr/generate/preset`: `{preset*, payload*, ...style}`. See Deep Dive
QR Engine for the field table.

```bash
curl -X POST localhost:4009/qr/generate/preset -H "X-API-Key: KEY" \
  -H 'Content-Type: application/json' \
  -d '{"preset":"wifi","payload":{"ssid":"Dobadoba-Guest","password":"welcome2026"}}' --output wifi.png
curl -X POST localhost:4009/qr/generate/preset -H "X-API-Key: KEY" \
  -H 'Content-Type: application/json' \
  -d '{"preset":"vcard","payload":{"first_name":"Alice","last_name":"Banda","phone":"+265888111222"},"format":"datauri"}'
curl -X POST localhost:4009/qr/generate/preset -H "X-API-Key: KEY" \
  -H 'Content-Type: application/json' \
  -d '{"preset":"momo","payload":{"phone":"+265888123456","provider":"airtel","amount":15000,"currency":"MWK","reference":"INV-2026-001"}}' --output momo.png
```

## Batch · Scan · Meta

```bash
curl -X POST localhost:4009/qr/generate/batch -H "X-API-Key: KEY" \
  -H 'Content-Type: application/json' \
  -d '{"items":[{"preset":"url","payload":{"url":"https://dobadoba.com/order/1"},"format":"datauri"},{"preset":"tel","payload":{"phone":"+265888111222"},"format":"datauri"}]}'
curl -X POST localhost:4009/qr/scan -H "X-API-Key: KEY" -F "file=@pay.png"
# → {"success":true,"data":"https://dobadoba.com/pay/TXN-12345",...}
curl "localhost:4009/qr/presets" -H "X-API-Key: KEY"
curl "localhost:4009/qr/history?limit=5&operation=preset" -H "X-API-Key: KEY"
curl "localhost:4009/qr/stats?days=30" -H "X-API-Key: KEY"
```

## Status codes

`200` ok (batch always 200 with per-item status) · `400` validation/domain ·
`401` bad/missing key · `422` no QR in image · `500` unreadable upload.
